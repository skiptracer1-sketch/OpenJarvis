# Agent OS V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an installable `agent-os-v1` OpenJarvis preset plus original agent-role, mission, memory, and quick-start documentation, with focused CLI regression coverage.

**Architecture:** Reuse OpenJarvis's existing `orchestrator`, memory, tools, MCP, traces, scheduler, workflows, and dashboard. Keep the implementation additive: one new TOML preset, one new CLI choice, one focused test module, and one documentation package; do not introduce a parallel orchestration runtime.

**Tech Stack:** Python 3.10+, Click, pytest, TOML configuration, Markdown, OpenJarvis CLI.

## Global Constraints

- Preserve upstream compatibility; prefer additive files and a tiny isolated CLI edit.
- Use existing OpenJarvis primitives rather than duplicating orchestration, memory, tools, skills, scheduler, workflow, or dashboard systems.
- Require a verification pass in the operating doctrine before mission completion.
- Keep local-first model defaults and the API server bound to `127.0.0.1`.
- Do not copy paid third-party prompts, course text, private workflows, branding, or proprietary materials.
- V1 role names are Commander, Researcher, Builder, Operator, Verifier, and Memory Keeper.
- V1 starter missions are Deep Research, Build, Monitor, Business Ops, and Daily Brief.
